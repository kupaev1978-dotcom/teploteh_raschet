# ТеплоРасчёт

Мобильное веб-приложение (PWA) для теплотехнического расчёта ограждающих
конструкций — **стен и перекрытий** — по **СП 50.13330.2024** «СНиП 23-02-2003
Тепловая защита зданий» (действует с 16.06.2024) и **СП 131.13330.2025**
«Строительная климатология» (действует с 09.09.2025).

Устанавливается на iPhone как ярлык с экрана «Домой» и работает офлайн.
Без App Store, без аккаунта Apple Developer.

## Возможности

- **Объектный уровень**: несколько конструкций в одном проекте, сводный отчёт,
  комплексное требование kоб (прил. Д: kоб = Σn·A/R₀пр / Vот против
  нормируемой по формулам (5.5)–(5.6))
- Климат по **всем 549 пунктам таблицы 5.1 СП 131.13330.2025** (с регионами,
  месячными температурами и парциальными давлениями для влажностного
  расчёта, скоростью ветра для воздухопроницания) + свой пункт из UI
- Четыре категории зданий (таблица 3 СП 50.13330.2024): 1.1 жилые,
  1.2 дошкольные/образовательные/медицинские (ГСОП по периоду ≤ 10 °С),
  2 общественные, 3 производственные
- Условия эксплуатации А/Б — автоматически по таблицам 1 и 2 СП 2024,
  с ручным переопределением
- Послойный конструктор: ~110 материалов из **приложения М СП 50.13330.2024**
  (λ при условиях А/Б), свои материалы, правка λ каждого слоя
- Базовое значение Rтр по таблице 3 (линейная формула a·ГСОП + b либо
  линейная интерполяция между табличными точками для категорий 2 и 3),
  Rнорм = mр·Rтр (mр = 1)
- R₀ = 1/αв + Σ(δ/λ) + 1/αн, вердикт с запасом; αн — по таблице 6
- Санитарно-гигиеническое требование п. 5.7: температура внутренней
  поверхности ≥ точки росы (расчётная влажность по назначению помещения);
  дополнительная проверка по формуле (5.4) с Δtн из таблицы 5
- Подбор толщины утеплителя (точная и ближайшая стандартная)
- Предупреждения о конденсате (на поверхности и в толще), график температур
- Сохранение расчётов на устройстве (localStorage), миграция расчётов,
  сохранённых в версиях по СП 2012
- Отчёт для печати/PDF с ходом расчёта и ссылками на СП

## Установка на iPhone (после публикации)

1. Откройте адрес приложения (например `https://<логин>.github.io/teplo-raschet/`) в **Safari**.
2. «Поделиться» → **«На экран „Домой"»** → «Добавить».
3. Иконка появится на рабочем столе. Приложение открывается на весь экран и
   работает офлайн (первое открытие должно быть онлайн).

## Локальный запуск (для разработки)

```bash
cd teplo-raschet
python3 tools/devserver.py 8017   # сервер без кеширования
# открыть http://127.0.0.1:8017
```

## Публикация на GitHub Pages

Вариант А (если установлен и авторизован `gh` CLI):

```bash
git init && git add -A && git commit -m "ТеплоРасчёт"
gh repo create teplo-raschet --public --source . --push
gh api repos/{owner}/{repo}/pages -X POST -f build_type=legacy -f 'source[branch]=main' -f 'source[path]=/'
```

Вариант Б (вручную): создайте публичный репозиторий `teplo-raschet` на
github.com, затем:

```bash
git remote add origin https://github.com/<логин>/teplo-raschet.git
git push -u origin main
```

и в настройках репозитория: **Settings → Pages → Deploy from a branch →
main / (root)**. Бесплатный GitHub Pages работает только с публичными
репозиториями.

### Обновления

После изменения файлов увеличьте `VERSION` в `sw.js` и сделайте `git push` —
установленное приложение обновится при следующем открытии онлайн.

## Контрольный пример (сверка расчёта, СП 2024/2025)

Москва (t⁵ = −23 °С, tот = −1,7 °С, Zот = 202 сут, зона сухая), здание жилое
(категория 1.1), tв = 20 °С, φв = 55 % → режим «нормальный», условия
эксплуатации **А**.

Стена (изнутри → наружу), λ по прил. М:

| Слой | δ, мм | λ, Вт/(м·°С) | R, м²·°С/Вт |
|---|---|---|---|
| Раствор цементно-песчаный 1800 | 20 | 0,76 | 0,026 |
| Кладка из глиняного обыкновенного кирпича на ЦПС 1800 | 380 | 0,70 | 0,543 |
| Минераловатные изделия из каменного волокна 40–60 кг/м³ (утеплитель) | 50 | 0,040 | 1,250 |
| Кладка из керамического пустотного кирпича 1000 (брутто) на ЦПС 1200 | 120 | 0,47 | 0,255 |

Плёнки: 1/8,7 = 0,115; 1/23 = 0,043.

- ГСОП = 21,7 · 202 = 4383 °С·сут
- Rтр = 0,00035·4383 + 1,4 = 2,93; Rнорм = mр·Rтр = 2,93 (mр = 1)
- **R₀ = 2,23 м²·°С/Вт** — 2,23 < 2,93, поэлементное требование **не
  выполняется**; требуемая толщина минваты ≈ 78 мм → стандартная 80 мм
- Санитарное требование п. 5.7: tв.п = 17,8 °С ≥ tр = 10,7 °С (20 °С / 55 %) —
  выполняется

## Оговорка о нормативных данных

Климатическая база извлечена автоматически из официального PDF
СП 131.13330.2025 (скрипт `tools/parse_sp131.py`) и сверена выборочно;
λ материалов — по приложению М СП 50.13330.2024. **Перед применением в
реальных проектах ключевые значения стоит сверить с официальными изданиями СП
и протоколами испытаний конкретных материалов.** Любое значение климата и λ в
приложении меняется вручную; ответственность за расчёт остаётся за инженером.

Пункты, исключённые из перечня СП 131.13330.2025 (Балаково, Магнитогорск,
Набережные Челны, Нижневартовск, Новокузнецк, Пятигорск, Стерлитамак,
Тольятти, Череповец), в базе отсутствуют — для них вводите климат вручную.
Зона влажности присвоена городам приближённо по карте прил. А
СП 50.13330.2024 и при необходимости переопределяется вручную.

## Структура

```
teplo-raschet/
├── index.html            # разметка приложения
├── css/style.css         # стили (светлая/тёмная тема, печать)
├── js/app.js             # состояние + миграция версий + SW
├── js/ui.js              # экраны, слои, модалки, график
├── js/calc.js            # расчётное ядро (СП 50.13330.2024)
├── js/report.js          # отчёт для печати/PDF
├── data/cities.js        # климат городов РФ (СП 131.13330.2025)
├── data/materials.js     # база материалов (прил. М СП 50.13330.2024)
├── tools/gen_icons.py    # генератор иконок (python3 tools/gen_icons.py)
├── tools/parse_sp131.py  # извлечение климата из официального PDF
├── tools/devserver.py    # dev-сервер без кеширования
└── icons/*.png, manifest.webmanifest, sw.js
```
